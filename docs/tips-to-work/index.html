# Working Directory en R Markdown
- **Por defecto**: el working directory es la carpeta donde está guardado el `.Rmd`.  
- Esto significa que las rutas de archivos (`.csv`, `.txt`, `.xlsx`) se interpretan **relativas a esa carpeta**.
```{r eval=FALSE}
1. Mismo folder
├── analisis.Rmd
├── datos.csv

data <- read.csv("datos.csv")
```

```{r eval=FALSE}
2. Subcarpeta dentro del folder del .Rmd
Proyecto/
├── analisis.Rmd
└── data/
    └── datos.csv

data <- read.csv("data/datos.csv")
```
